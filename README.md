# 📊 Amazon Electronics Sales Data Analysis

## 📌 Overview

This project explores **Amazon Electronics Sales Data** using Python to uncover meaningful business insights. Through **Exploratory Data Analysis (EDA)**, data cleaning, and visualization, the project identifies customer purchasing patterns, product performance, and sales trends.

The analysis demonstrates how data analytics can support business decision-making by transforming raw data into actionable insights.

---

## 🎯 Project Objectives

* Load and explore the dataset using Python.
* Clean and preprocess the data.
* Perform Exploratory Data Analysis (EDA).
* Analyze customer behavior and purchasing patterns.
* Identify top-performing products and categories.
* Discover sales trends through visualizations.
* Generate business insights for strategic decision-making.

---

## 📂 Dataset

The dataset contains information related to Amazon electronics sales, including:

* Product Details
* Customer Ratings
* Prices
* Discounts
* Categories
* Reviews
* Sales-related information

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Yuvrajpatel-01/analyzing_amazon_electronics_sales_data.git
```

2. Navigate to the project directory

```bash
cd analyzing_amazon_electronics_sales_data
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Open the Jupyter Notebook

```bash
jupyter notebook
```

5. Run all notebook cells to reproduce the analysis.
